# Amphiptere OS // Global Tactical Map

A lightweight tactical global tracking simulation built by **Amphiptere OS**. Features a dark hacker-style web interface that dynamically streams simulated global tracking nodes.

## Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/AmphiptereOS/Amphiptere-OS-Map.git](https://github.com/AmphiptereOS/Amphiptere-OS-Map.git)
   cd Amphiptere-OS-Map

   
To Run this :
GO must be Installed.

go run amphiptere-map.go 

Open Browser and navigate to:
http://localhost:8080
